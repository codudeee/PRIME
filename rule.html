RULE 01

기본 진행 규칙

경기 시작 전 확인해야 하는 기본 진행 안내입니다.

수정할 본문을 직접 클릭해서 편집한 뒤 저장하세요. 저장된 룰은 Supabase에 유지됩니다.

기본 안내

여기에 기본 진행 규칙을 작성하세요.

  • 참가 조건, 대기 순서, 시작 기준 등을 정리하세요.
  • 경기 전 확인해야 할 내용을 적으면 됩니다.

진행 방식

방송/디스코드/시트지 기준으로 어떤 순서로 경기가 진행되는지 작성하세요.

점수 기준

여기에 점수 계산 규칙을 작성하세요.

  • 킬 점수, 다이 감점, 치킨 점수 등을 정리하세요.
  • 회원 티어별 목표점수나 감점 기준을 적으면 됩니다.

정산 안내

정산 타이밍, 확인 방식, 이의제기 기준 등을 작성하세요.

서렌 기준

여기에 서렌 가능 조건과 처리 방식을 작성하세요.

콜드 기준

점수 차이, 콜드 상태 안내, 불판 사용 또는 서렌 선택 기준 등을 작성하세요.

불판 사용

여기에 불판 사용 조건을 작성하세요.

  • 불판 사용 가능 상황을 정리하세요.
  • 불판 이후 점수/라운드 처리 기준을 작성하세요.

경고 기준

여기에 경고 사유와 누적 처리 기준을 작성하세요.

제재 기준

핵, 대리, 티어 속임수, 고의 트롤 등 제재 대상을 정리하세요.

운영 기준

여기에 운영진 판단 기준과 예외 처리 기준을 작성하세요.

문의 안내

문의 채널, 처리 순서, 디스코드 안내 등을 작성하세요.
